# 🧠 Recent Memory

> Projeto desenvolvido como trabalho de conclusão do **Programa Transforme-Se** (Serasa Experian em parceria com o SENAI).

---

## 📝 Descrição

O **Recent Memory** é uma aplicação criada para auxiliar pessoas que enfrentam perda de memória recente e possuem dificuldades em se lembrar de tarefas e atividades cotidianas. O objetivo principal do projeto é proporcionar mais organização, autonomia e facilidade no dia a dia dos usuários.
